# OneKey

> OneKey is a self-custody crypto wallet company ("Self Custody. Open Source. Fully Onchain.") building open-source hardware wallets (OneKey Pro, Classic 1S, Lite) and cross-platform software wallets, secured by an EAL6+ secure element and ISO/IEC 27001-certified operations. Its developer surface is the open-source Hardware JS SDK, an injected dApp provider (EIP-1193), air-gap QR signing, and the private-beta Agent Wallet for AI agents. Backed by Coinbase Ventures, Dragonfly, Ribbit Capital, and YZi Labs.

This llms.txt was generated by API Evangelist from the OneKey developer surface and the api-evangelist/onekey catalog record. OneKey publishes no hosted REST API/OpenAPI; integration is via client SDKs and the injected provider.
